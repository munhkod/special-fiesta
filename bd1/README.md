# APL121 · Бие даалт №1 — Code Quest

**Сэдэв №12: Тооны шидэт хүснэгт**

Хэрэглэгч 3 тоо болон хүснэгтийн мөрийн тоог оруулна. Программ 3 тооны үржүүлэх хүснэгтийг зэрэгцүүлж
хэвлээд, тоо бүрийн тэгш/сондгой, цифрийн нийлбэр, урвуу тоо, ангилал, «шидэт» эсэхийг хүснэгтээр гаргана.
Эцэст нь хамгийн их цифрийн нийлбэртэй тоог олно.

## Ажиллуулах

```bash
gcc main.c -o main
./main
```

Flowgorithm: `quest.fprg` файлыг нээгээд **Run** дарна.

## Өөрийн тогтоосон дүрмүүд

1. **Тооны хязгаар:** 1–99999 (5 хүртэл оронтой эерэг бүхэл тоо). Өөр утга орвол do-while-аар дахин асууна.
2. **Хүснэгтийн мөр:** 5–10. Хүснэгт `тоо × 1`-ээс `тоо × мөр` хүртэл.
3. **Ангилал** (цифрийн нийлбэрээр):

   | Нийлбэр | Ангилал |
   |---------|---------|
   | 1 – 9 | Baga |
   | 10 – 18 | Dund |
   | 19+ | Ih |

4. **Шидэт тоо:** дараах хоёрын аль нэг нь биелбэл «Tiim *»:
   - 2 ба түүнээс дээш оронтой **тольт тоо** (урвуу нь өөртэйгөө тэнцүү, жишээ 808, 12321), **эсвэл**
   - цифрийн нийлбэр нь **7** (Монголд 7 бол азын тоо гэж үздэг).
5. **Урвуу тоо:** төгсгөлийн тэгүүд алга болно (1230 → 321, 100 → 1).
6. **Хамгийн их нийлбэр:** хоёр тоо тэнцүү бол эхэнд оруулсан нь сонгогдоно.

## Жишээ гаралт (Тест 1: `12321`, `1234`, `7`, `5`)

```
=== TOONY SHIDET HUSNEGT ===
1-r too (1-99999): 12321
2-r too (1-99999): 1234
3-r too (1-99999): 7
Urjuuleh husnegtiin mor (5-10): 5

--- Urjuuleh husnegt ---
x         12321       1234          7
-------------------------------------
1         12321       1234          7
2         24642       2468         14
3         36963       3702         21
4         49284       4936         28
5         61605       6170         35

--- Toony medeelel ---
Too      Turul     Niilber    Urvuu  Angilal Shidet
-------------------------------------------------------
12321    Sondgoi         9    12321  Baga    Tiim *
1234     Tegsh          10     4321  Dund    Ugui
7        Sondgoi         7        7  Baga    Tiim *

Hamgiin ih tsifriin niilbertei too: 1234 (niilber = 10)
```

> Windows консол дээр кирилл үсэг эвдэрч, `%-8s` нь кирилл үсгийг 2 байтаар тоолж багана
> гажих тул гаралтыг латин үсгээр бичсэн.

## Заавал байх 7 элемент хаана байгаа вэ

| № | Элемент | Хаана |
|---|---------|-------|
| 1 | Оролт/гаралт | 4 `scanf` (3 тоо + мөрийн тоо), `printf` хоёр хүснэгт |
| 2 | Арифметик + логик | `%`, `/`, `*` цифр задлахад; `(n == rev && n >= 10) \|\| sum == 7`, `n < 1 \|\| n > 99999` |
| 3 | else-if шат | Ангилал (Baga / Dund / Ih), тэгш/сондгой |
| 4 | Давталт + хүснэгт | `for` үржүүлэх хүснэгт 5–10 мөр (`%-4d %10d`), мэдээллийн хүснэгт (`%-8d %-8s %8d`) |
| 5 | Дэд алгоритм | Flowgorithm: `ReadNumber`, `DigitSum`, `Reverse` (Function), `PrintInfo` (Call блок) |
| 6 | Хайлт | 3 тооны хамгийн их цифрийн нийлбэрийг `if`-ээр олох |
| 7 | Оролтын шалгалт | `do-while` (`readNumber` дотор + мөрийн тоо) |
